# GeoNarrative Studio

GeoNarrative Studio 是一个环境研究决策工作台，将土地利用情景配置、约束检查、模型验证和技术路线图整合为一条连续的产品工作流。

## 在线 Demo

<https://niubition.github.io/ZYS-aiPM-CV/>

## 核心交互

- 土地利用情景选择与需求调整
- 配置可达性提醒
- 地图格局与土地类型占比变化
- 多类环境研究技术路线图生成
- 桌面端与移动端响应式展示

网页中的土地利用地图是产品交互原型，不执行真实栅格模型计算。
